# Guess My Number 🎯

A simple browser game built with vanilla JavaScript, HTML, and CSS. The computer picks a random number between 1 and 20, and you try to guess it in as few tries as possible.

## How to play

1. Open `index.html` in your browser.
2. Enter a number between 1 and 20 in the input field.
3. Click **Check!**
   - If your guess is too high or too low, you'll get a hint and lose a point from your score.
   - If your guess is correct, you win! The background turns green and the secret number is revealed.
4. Your score starts at 20 and decreases with each wrong guess. If it hits 0, the game is over.
5. Beat your **Highscore** by winning with the highest score possible.
6. Click **Again!** to reset the game and play another round.

## Tech stack

- HTML
- CSS
- JavaScript (DOM manipulation, event listeners)

## Run it locally

Just open `index.html` in any modern web browser — no build steps or dependencies required.
